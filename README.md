# HTML-AND-CSS-PROJECTS
This repository contains a collection of HTML and CSS coding projects completed as part of The Tech Academy's Software Developer Bootcamp.

## Projects
* Academy Cinemas
* Creating CSS Effects
* One Page Website
* Simple Recipes
* Student's WebPortfolio
* The Pet Shop Website

### Academy Cinemas
A simple and elegant website built with HTML and CSS, designed to showcase movie listings, schedules, and theater contact information in an organized way. The structure uses flexbox and CSS grid to create a responsive layout that adapts across different screen sizes. The website highlights essential sections such as Now Playing, Tickets, and Contact, providing a realistic example of how a cinema or entertainment-based site could be structured.

### Creating CSS Effects
A small collection of CSS animations and hover effects that can be applied to images and other elements to make websites more interactive. The project explores the use of hover transitions, scaling, and subtle movements to add extra visual appeal without relying on JavaScript or external libraries. These effects help demonstrate how CSS alone can bring static pages to life and improve user engagement by providing immediate feedback to interactions.

### One Page Website
A minimalistic one-page website for an auto parts store. The design includes several sections, such as the store name, an embedded introductory video, a quick car brand selector, a photo gallery, and contact information, all structured on one continuous scrollable page. Navigation is done using anchor links, making it easy to jump between sections without leaving the page. The project is an exercise in creating a focused, visually appealing site that presents all content in a compact and efficient format. It emphasizes the importance of clear sectioning, smooth navigation, and creating a simple yet effective user experience.

### Simple Recipes
A clean and well-organized recipe-sharing website that presents different dishes in a card-based layout. Each card includes an image, a list of ingredients, and step-by-step instructions, making the content easy to follow and visually engaging. The site is built with HTML and CSS, with an emphasis on readability and straightforward presentation. The project demonstrates how to build a blog-style website, where content can be categorized, formatted consistently, and displayed in a way that feels approachable for users looking for quick access to information.

### Student's WebPortfolio
A sample portfolio website created to demonstrate how personal projects, skills, and information can be presented professionally. In addition to the HTML structure, the project includes CSS animations and transitions that give the site a more dynamic look. This project serves as practice in creating a website that a student or developer could use to share their work online, combining functionality with visual appeal.

### The Pet Shop Website
A basic online website created for a fictional pet store, featuring a variety of sections such as pet categories, a home page, embedded pet videos, and a contact form. The project is built using HTML to give the site a meaningful structure and CSS for styling, which helps make the layout accessible and easy to navigate. This project serves as a small-scale example of an e-commerce style site, showing how a store could present its products and information in a simple yet effective way.
